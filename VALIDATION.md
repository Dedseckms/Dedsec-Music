# Проверка проекта

Проверки запускаются из корня; команды перечислены в [руководстве по сборке](docs/BUILDING.md).

Автоматические проверки покрывают протокол сервера, отмену запросов, изоляцию аккаунтов, очередь, поиск, перенос, разбор манифестов обновления и проверки настольного клиента. Отдельные инструменты проверяют установку/удаление Windows и применение обновления во временном каталоге.

Физические сценарии — звук на устройстве, системный установщик Android, Android Auto и оформление уведомлений конкретной прошивки — проверяются на соответствующих устройствах. Успешный JVM-тест не заменяет такую проверку.
