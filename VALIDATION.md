# Проверка проекта

Проверки запускаются из корня; команды перечислены в [руководстве по сборке](docs/BUILDING.md).

Автоматические проверки покрывают протокол сервера, отмену запросов, изоляцию аккаунтов, очередь, поиск, перенос, разбор манифестов обновления и проверки настольного клиента. Отдельные инструменты проверяют установку/удаление Windows и применение обновления во временном каталоге.

Физические сценарии — звук на устройстве, системный установщик Android, Android Auto и оформление уведомлений конкретной прошивки — проверяются на соответствующих устройствах. Успешный JVM-тест не заменяет такую проверку.

## Выпуск 0.7.0 · 15 ноября 2026

- Общий протокол: 16 тестов; Android: 69 тестов и release APK; Windows: 26 тестов и комплект с Java/libVLC.
- iPhone Preview 0.1.2: 13 Swift-тестов и успешная сборка Release для устройства на macOS. IPA не подписана; подпись добавляет AltStore.
- Серверное дополнение: 83 теста на Python 3.14, два POSIX-сценария пропущены на Windows; Linux-проверки безопасности дискового копирования выполнены отдельно.
- Офлайн-сценарии включают восстановление очереди после частичной ошибки записи и восстановление индекса после публикации аудиофайла.
- Панель сервера отрисована из настоящих компонентов на широком и узком экране с демонстрационными данными.

Телефон для инструментальных замеров не подключался. Убраны полные обходы офлайн-библиотеки на пути запуска трека и при каждом обновлении очереди; устранение наблюдавшейся задержки около 30 секунд на конкретном Android-устройстве пока не подтверждено. Проверка файловых fixtures не заменяет перенос реальной библиотеки на новый физический диск.

## Выпуск 0.7.1 · тексты и единый вход

Общий протокол: 21 тест; Android: 69; Windows: 26. Проверяются переходы по таймкодам, отсутствие выдуманной разметки для обычного текста, офлайн-кеш и единственный POST загрузки при HTTP 408. iPhone: 15 Swift-тестов и Release-сборка устройства в GitHub Actions. Серверное дополнение: 96 тестов (два POSIX-сценария пропущены на Windows), включая изоляцию пользователей, доступ к кешу текстов и проверку интернет-совпадений; настоящий Navidrome 0.64.2 проверен в изолированном fixture с соседним LRC.

Физическая проверка экрана текста и единого входа на устройствах выполняется отдельно. Пословная подсветка, автоматическое выравнивание текста и модели второго сервера не входят в этот выпуск.
## Выпуск 0.7.3 / Windows 0.4.2

Протокол: 24 теста; Android: 69 тестов и подписанный release APK; Windows: 28 тестов и полный комплект. Проверены полный цикл повтора и переход обычная очередь → волна; роль передаётся только на фиксированный путь с музыкальной авторизацией. Окно текста заменено встроенной сценой; отрисованы широкая и компактная версии с оригинальными демонстрационными обложкой и строками. Проверка установки/удаления Windows и комплектного аудиодвижка пройдена.

Серверное дополнение: 111 тестов, два POSIX-сценария пропущены на Windows. Проверяются ограниченное чтение нейровекторов, персональное сходство в настоящем подборе, отрицательные оценки, устаревшие аренды, ошибки источника и сохранение малых значений при квантовании. Изменения ролей проверены также на изолированном Navidrome 0.64.2.

Android-жесты и размытие на физическом телефоне ещё не проверены. Наличие таймкодов для всей библиотеки не гарантируется. Нейроанализ звучания не выполняет распознавание слов или выравнивание текста.

## Выпуск 0.7.4 / Windows 0.4.3

Серверная поправка текста сохраняется только владельцем, привязана к версии аудио и таймкодов; назначенные администраторы не получают это право. Проверяются конфликт ревизий, строгие границы, сохранение после перезапуска, доступ только к видимым трекам и отсутствие права записи из офлайн-кеша. Физические устройства в текущей проверке не использовались.

## Выпуск 0.7.5 / Windows 0.4.4

Android следует за активной строкой с учётом реальной высоты области; настройки сдвига вынесены в отдельный диалог. В панели сервера есть очередь поиска текстов и счётчики настоящих результатов. Серверные тесты проверяют возобновление, приоритет открытых текстов, ограничение запросов, JWT-free фоновый guard и остановку при отзыве владельца. Физический Android для проверки не подключался.

## Выпуск 0.7.6 / Windows 0.4.5

Общий протокол: 32 теста; Android: 69; Windows: 28. Подписанный APK и комплект Windows собраны; проверка установщика и обновления на временных файлах пройдена. Проверяются необязательный прогресс выравнивания и совместимость с прежним сервером. Физические устройства не подключались.

Серверные проверки покрывают аренду задания, отдельную авторизацию воркера, сохранение ручных поправок, исходной ревизии и порядка строк, ограничения PCM и повторную публикацию. На Linux отдельно пройдены проверки приватного файла токена и настоящего контракта broker → worker. Выравнивание экспериментальное: структурная проверка и акустический результат не гарантируют точность строк на любой песне.
