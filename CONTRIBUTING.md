# Участие в проекте

Для ошибки создай issue с платформой, версией и шагами воспроизведения. Для большой функции сначала опиши сценарий использования. Не прикладывай пароли, токены, серверные базы и личные музыкальные файлы.

Перед pull request запусти подходящие [проверки](docs/BUILDING.md), опиши изменение поведения и ограничения проверки. Изменения общего протокола должны сохранять совместимость Android, Windows и серверного дополнения.

Проект распространяется на условиях GPL-3.0-or-later. Заимствованный код должен иметь совместимую лицензию и сохранять авторские уведомления. Ключи подписи и локальные настройки не добавляются в Git.
