# DedSec Music для Windows

Открой приложение и введи HTTPS-адрес Navidrome, логин и пароль. Адрес загрузчика указывается отдельно во вкладке «Добавить», если администратор включил серверное дополнение.

- **Главная** — моя волна и последние альбомы. Настроение меняется кнопкой «Настроить» у волны.
- **Поиск** — треки, исполнители, жанры и недавние запросы.
- **Библиотека** — коллекция сервера, альбомы и личные плейлисты.
- **Любимое / Скачанное** — избранное аккаунта и офлайн-копии на этом компьютере.
- **Добавить** — аудиофайлы и перенос коллекции с Яндекс Музыки.
- **Профиль** — аватарка, палитра, оформление и обновления.

Кнопки воспроизведения доступны внизу окна, очередь — справа. При узком окне очередь открывается отдельной панелью. Приложение поддерживает тёмную, светлую и AMOLED-темы.

Следующий трек заранее подготавливается в отдельном декодере. При обычном завершении композиции длительностью от восьми секунд последние 2,5 секунды плавно смешиваются с началом следующей. Ручное переключение сразу запускает выбранный трек; если предзагрузка недоступна, используется обычное переключение.

Java и libVLC включены в установку. Сохранённый пароль защищён Windows DPAPI. Данные аккаунтов находятся отдельно от файлов программы в пользовательском каталоге приложения.

Обновления проверяются через GitHub при запуске и каждые шесть часов. Предложение появляется поверх любого экрана; проверку можно повторить в профиле. После нажатия «Обновить» виден прогресс загрузки, затем программа перезапускается. Проверяются подпись манифеста, размер и SHA-256 архива. Загрузку можно отменить; при неудачном запуске новой версии предусмотрен откат.

Если Windows 0.3.0 или 0.3.1 не обновляется, один раз запусти [новый установщик](https://github.com/Dedseckms/Dedsec-Music/releases/latest). Это заменит старый механизм обновлений; данные аккаунта хранятся отдельно.
