# Архитектура и платформы

| Платформа | Текущее состояние |
| --- | --- |
| Android 8.0+ | Нативный клиент Jetpack Compose / Media3, исходники в `app/`. |
| Windows x64 | Compose Desktop / libVLC, широкая компоновка, установщик Inno Setup, исходники в `desktop/`. |
| iPhone / iOS 17+ | Нативный SwiftUI / AVPlayer-клиент в `ios/`. Предварительная версия IPA для AltStore: [установка](IPHONE.md). |
| macOS | Запланирован клиент с системной интеграцией. Готовой сборки нет. |

## Модули

- `shared/protocol/` — модели, OpenSubsonic/Navidrome, очередь, поиск, персональный микс, профили, перенос и протокол обновлений Android.
- `app/` — Android UI, MediaLibraryService, офлайн-загрузки и системная интеграция.
- `desktop/` — Windows UI, libVLC, локальное хранилище, защита сохранённого пароля Windows DPAPI и подписанные обновления.
- `ios/` — SwiftUI, AVPlayer, Keychain, системное управление воспроизведением и Swift-пакет протокола. [Установка через AltStore](IPHONE.md).
- `server/` — комплект самостоятельного развёртывания и дополнение к Navidrome: профили, проверка загрузок и фоновые задачи переноса.
- `branding/` — единая иконка и графические ресурсы. Источник иконки — Android vector drawable.
- `tools/` — подготовка инструментов, подписание, упаковка и проверка установщика.

## Принципы

Клиенты не требуют общего публичного облака. Администратор выбирает сервер, создаёт аккаунты и управляет библиотеками. Аудиотека может быть общей; плейлисты и избранное принадлежат пользователям. Секреты не включаются в исходники и релизные пакеты.

Перенос живёт на сервере и не зависит от открытого экрана приложения. Журнал отделён от токена источника. Обновления берутся из одного GitHub-репозитория; Android доверяет подписи установленного приложения, Windows — встроенному публичному ключу манифеста.
