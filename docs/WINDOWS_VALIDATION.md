# Проверки Windows

Основные команды: [сборка и тесты](BUILDING.md). Тесты настольного модуля проверяют очередь с повторяющимися ID, перемешивание, завершение одиночного трека, кэш обложек, отмену сетевых запросов, ограничения изображений, палитры, сохранение оформления и проверку подписи обновлений.

`tools/test-installer.ps1` использует отдельный временный каталог и проверяет установку, локальный запуск libVLC, удаление обновлённого payload и сохранность внешнего файла. `tools/test-update.ps1` проверяет предварительные условия, откат после замены каталога и отказ при небезопасном пути ZIP.

Скриншоты из `desktop:renderGallery` используют настоящие экраны приложения и демонстрационные данные. Проверка звука через `desktop:audioSmoke` использует сгенерированный WAV и тестовый аудиовыход.

Проверка аудиодвижка также покрывает беззвучную предзагрузку, переход между двумя декодерами, однократное продвижение очереди, паузу и продолжение в середине перехода, ручное переключение на подготовленный трек и последующую перемотку. Геометрия восстановления развёрнутого окна проверяется для обычного монитора и отрицательных координат второго экрана.

Это не заменяет проверку на физическом устройстве, прослушивание через динамики и проверку реального входа на конкретном сервере. Windows EXE не подписан Authenticode; Ed25519 защищает манифест встроенного обновления отдельно.
