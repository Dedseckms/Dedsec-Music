# Перенос из Яндекс Музыки

Перенос запускается во вкладке **«Добавить» → «Из Яндекс Музыки»** на Android и Windows. Файлы скачивает музыкальный сервер: телефон или компьютер можно закрыть. Нужны свой музыкальный аккаунт и сервер с включённым дополнением DedSec Music.

## Получить токен

Открой [инструкцию разработчика библиотеки Yandex Music API](https://ym.marshal.dev/token/). Она описывает актуальные способы входа; если Яндекс изменит авторизацию, сначала проверь её.

**Через браузер:**

1. Открой [страницу выдачи доступа Яндекса](https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d).
2. Войди на странице Яндекса и подтверди доступ. Проверь, что авторизация идёт на домене Яндекса.
3. После подтверждения в адресе перенаправления найди `access_token=…`. Скопируй только значение до следующего `&`.
4. Если перенаправление слишком быстрое, используй описанный в инструкции способ с замедлением сети или OAuth Device Flow.

На Android альтернативный инструмент со своими исходниками доступен у [разработчика Yandex Music API](https://github.com/MarshalX/yandex-music-token). Устанавливать его для DedSec Music необязательно.

## Запустить перенос

Вставь токен в скрытое поле и нажми **«Перенести коллекцию»**. Он передаётся по HTTPS только настроенному музыкальному серверу, не GitHub. Поле очищается после отправки.

Сначала идёт сбор разделов коллекции и отбор музыки. На этом этапе отображается число найденных записей: итог ещё неизвестен. После отбора появятся процент, число обработанных треков и текущая композиция.

- **Скачано** — новые файлы, сохранённые на сервер.
- **Уже на сервере** — проверенные файлы с тем же ID источника; повторно не загружаются.
- **Недоступно** — источник не отдаёт аудио для аккаунта.
- **Ошибки** — записи, которые не удалось перенести после ограниченного числа повторов.
- **Исключено** — аудиокниги, подкасты и неподходящие записи.

Файл сохраняется один раз, а ссылка на него включается в личные плейлисты импортирующего пользователя. Названия, порядок и повторения внутри плейлиста сохраняются. После сканирования каталогов сервер восстанавливает эти списки отдельно для каждого аккаунта.

Не редактируй импортируемые списки до завершения. Если обнаружены ручные изменения, сервер не должен их перезаписывать: такой список потребует отдельной проверки. В названия не добавляются технические ID; служебная привязка хранится в комментарии приватного плейлиста.

У одинаковых названий могут быть разные исполнения. Совпадение названия и исполнителя с вручную загруженным файлом не считается надёжным доказательством дубликата.

## Остановить или продолжить

Кнопка **«Остановить перенос»** завершает текущую операцию безопасно. Загруженное остаётся в библиотеке. Для продолжения вставь токен повторно; готовые записи берутся из журнала.

Токен хранится в оперативной памяти серверного процесса. После перезапуска сервера задача ждёт повторного ввода токена. У каждого аккаунта свой статус переноса; файлы попадают в общую разрешённую библиотеку. Новые файлы появляются в каталоге после сканирования Navidrome.

Токен даёт доступ к аккаунту: не публикуй его, не вставляй в сообщения и используй только сервер, которому доверяешь. Доступность аудио зависит от аккаунта и ответа источника; недоступные записи отмечаются в прогрессе.
