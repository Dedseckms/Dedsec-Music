# Тексты песен и единый вход

В плеере нажми кнопку «Текст песни». При наличии временной разметки текущая строка подсвечивается и прокручивается; нажатие на строку перематывает воспроизведение. После ручной прокрутки кнопка «К строке» возвращает слежение. Поправка тайминга действует в текущем открытом окне текста.

В Windows текст открывается внутри приложения рядом с большой обложкой, а фон подстраивается под её цвета. Нижняя панель воспроизведения остаётся доступной. Повторное нажатие на кнопку текста возвращает библиотеку.

В Android текст накладывается на размытую обложку с полупрозрачным фоном. Кнопка текста включает и выключает этот вид. Горизонтальные свайпы по этой области переключают треки; вертикальная прокрутка позволяет читать строки. Подсветка меняется плавно. На старых Android, где размытие недоступно, читаемость сохраняет полупрозрачный фон.

В обычной очереди кнопка повтора переключает режимы **выключен → вся очередь → один трек → выключен**. В волне доступны **выключен → один трек**; положение остальных кнопок сохраняется.

Сначала сервер проверяет текст, доступный через Navidrome (теги или соседний LRC), затем ищет в LRCLIB. Название, исполнитель, длительность и обозначения версии записи учитываются при выборе. Для вручную добавленной музыки действует тот же поиск после появления трека в каталоге. При плохих тегах, неоднозначной версии или отсутствии записи в источнике текст может не найтись.

Обычный текст отображается без подсветки по времени. Генерация слов, транскрибация и автоматическая разметка таймингов не используются. Пословная караоке-подсветка пока не реализована. Найденный текст сохраняется в отдельном кеше текущего аккаунта; уже открытый текст можно просматривать без сети.

Запрос текста не участвует в запуске аудио. Первый запрос может показать «Ищем текст»; сервер продолжает работу независимо от открытого окна. Клиент ограниченно обновляет статус. Неудачи поиска кешируются с возможностью повторного поиска позже. Источник указан под текстом.

## Вход в загрузку

Сервер сообщает поддержку единого входа через `GET /dedsec/profile/v1/capabilities`. Клиент использует музыкальную сессию и фиксированный путь того же HTTPS-сервера `/dedsec/profile/v1/uploads`. Пароль не пересылается на произвольный адрес загрузчика. На совместимом сервере дополнительная форма входа скрыта.

Для старого или отдельно подключённого файлового сервера остаётся явная настройка его аккаунта. Единый вход в приложении не создаёт автоматически браузерную сессию веб-интерфейса Quantum. Общие ограничения 100 МБ / 20 минут и личные плейлисты сохраняются.

В «Моей волне» нет кнопки перемешивания и повтора всей очереди. Переключатель «Повторять один трек» зацикливает текущую песню; ручное переключение остаётся доступным.

## Второй сервер

Отдельный анализатор и модели пока не установлены. После подключения второго сервера сначала проверяются CPU-инструкции, память и производительность на небольшой выборке. Сохранённые результаты будут поступать на основной сервер; воспроизведение и волна не должны зависеть от доступности анализатора.

## Общая поправка синхронизации

Владелец сервера может изменить сдвиг текста кнопками ±0,25 с и нажать «Сохранить для всех». Поправка хранится на сервере для конкретной записи и автоматически применяется слушателям после получения текста; работает и из обновлённого офлайн-кеша. Другие пользователи, включая назначенных администраторов, не могут менять общую поправку. Положительный сдвиг опережает подсветку, отрицательный задерживает. При замене аудио или исходных таймкодов требуется новая калибровка. Старые локальные несохранённые поправки из предыдущих версий восстановить нельзя.

## Поиск по всей библиотеке

В «Мой сервер → Тексты» владелец видит прогресс фонового прохода: проверено, найдено с таймкодами, без таймкодов, инструментальные записи, не найдено и ошибки. Здесь можно приостановить и продолжить очередь. Приложение можно закрыть — работа продолжается на сервере. Общий кеш используется всеми слушателями с доступом к треку. Панель не выдаёт отсутствие таймкодов за успешную синхронизацию.

Android автоматически держит текущую строку в видимой зоне. После ручного просмотра автопрокрутка возобновляется через 3,5 секунды; также доступна кнопка возврата к строке. Настройка сдвига открывается кнопкой с ползунками и не занимает место у текста.
