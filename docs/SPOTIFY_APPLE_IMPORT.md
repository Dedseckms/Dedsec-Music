# Перенос из Spotify и Apple Music

Проверено 14 ноября 2026 года. Это оценка интеграции; кнопки подключения этих сервисов пока не добавлены в приложения.

## Что можно перенести

Плейлисты, названия треков, исполнителей, альбомы и доступные идентификаторы. Затем записи можно сопоставить с общей аудиотекой своего сервера и создать личные плейлисты, сохранив порядок и повторы. Совпадение метаданных само по себе не даёт аудиофайл: отсутствующие на сервере записи нужно показывать отдельно и добавлять из доступного владельцу источника.

## Spotify

Официальный Web API поддерживает чтение пользовательских плейлистов и сохранённых треков с разрешения аккаунта. Для клиента нужен OAuth Authorization Code с PKCE, а для приложения — собственный Client ID. Секрет приложения в Android, Windows или iPhone встраивать нельзя.

В режиме разработки действуют ограничения доступа, включая Premium у владельца приложения и лимит авторизованных пользователей. Нельзя обещать подключение любого аккаунта без проверки режима доступа приложения. В феврале 2026 года изменились endpoints и поля плейлистов; реализация должна использовать актуальный `/playlists/{id}/items` и учитывать пагинацию и ограничения частоты.

Обычный Web API предоставляет каталог и управление воспроизведением; это не API экспорта полноценных MP3/FLAC на домашний сервер. Предлагаемый вариант интеграции — перенос списков и сопоставление с собственной аудиотекой.

Источники: [изменения доступа и миграция API](https://developer.spotify.com/documentation/web-api/tutorials/february-2026-migration-guide), [плейлисты](https://developer.spotify.com/documentation/web-api/concepts/playlists), [PKCE](https://developer.spotify.com/documentation/web-api/tutorials/code-pkce-flow).

## Apple Music

Apple Music API позволяет читать личную медиатеку и плейлисты. Запросы требуют Developer Token, а личные данные — также Music User Token после разрешения пользователя через MusicKit. Для полноценной интеграции владельцу сервера потребуется настройка Apple Developer / MusicKit; закрытый ключ остаётся на сервере. Сам клиент не должен просить пользователя присылать пароль Apple ID.

MusicKit предназначен для доступа к каталогу и воспроизведения в рамках сервиса. Обычный сценарий переноса на наш сервер — метаданные, порядок плейлистов и сопоставление существующих файлов, а не экспорт защищённого аудио.

Источники: [Apple Music API](https://developer.apple.com/documentation/applemusicapi), [аутентификация MusicKit](https://developer.apple.com/documentation/applemusicapi/user-authentication-for-musickit).

## Путь без ключей разработчика

Импорт экспортированного пользователем CSV / JSON со списками треков может работать независимо от OAuth и лимита тестовых пользователей. Следующий этап такой интеграции: предварительный просмотр, точное сопоставление по ISRC при наличии, затем по нормализованным названию и исполнителю; неоднозначные совпадения подтверждаются пользователем. Ненайденные треки не должны подменяться похожими версиями без подтверждения.
