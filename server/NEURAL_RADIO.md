# Фоновый анализ звучания

Дополнительный процесс анализирует короткие фрагменты с помощью [YAMNet](https://www.tensorflow.org/hub/tutorials/yamnet) и возвращает 521 числовой признак. Это классификатор звуков, а не генератор музыки или распознавание слов.

Волна читает сохранённые признаки: похожее на любимые и часто дослушиваемые треки получает больший вес, похожее на отклонённые — меньший. Настройки настроения продолжают применяться как фильтры. Отсутствие готовых признаков не задерживает воспроизведение. На запрос проверяются максимум 384 доступных пользователю вектора.

## Отдельный компьютер

Воркер проверен на Linux x86_64, i5-2410M без AVX2 с LiteRT 2.3.0: один вычислительный поток; четыре тестовых кадра — около 51 МБ RSS, 0,05 секунды. Это короткая проба, не нагрузочный тест библиотеки.

Понадобятся отдельное Python-окружение с `ai-edge-litert==2.3.0` и NumPy, `neural-worker.py` и модель. Официальная [модель Google](https://tfhub.dev/google/lite-model/yamnet/classification/tflite/1?lite-format=tflite) не включена в исходники; принимается только SHA-256 `10c95ea3eb9a7bb4cb8bddf6feb023250381008177ac162ce169694d05c317de`.

Создайте отдельный случайный токен из 64 шестнадцатеричных символов. На музыкальном сервере он хранится в `STATE_ROOT/radio/worker.token`, на воркере — в отдельном файле. Файлы принадлежат пользователю процесса, права `0600`. Передавайте токен по защищённому каналу, не помещайте в URL или текст аргумента команды. Музыкальный пароль воркеру не нужен.

```bash
venv/bin/python neural-worker.py --model /absolute/path/yamnet.tflite --smoke
venv/bin/python neural-worker.py \
  --origin https://music.example.org \
  --model /absolute/path/yamnet.tflite \
  --token /absolute/path/worker.token \
  --stop /absolute/path/worker.stop
```

Воркер получает только короткий PCM-фрагмент и одноразовую аренду задания. Пути, история аккаунтов и пароли не передаются. Один процесс выполняет задания не чаще раза в 30 секунд. Результат проверяется по модели, сроку аренды и версии файла; ошибки источника получают паузу перед повтором.

Файл `worker.stop` останавливает процесс между запросами. Файл `STATE_ROOT/radio/neural.pause` отключает выдачу заданий и использование нейропризнаков. При недоступном втором компьютере основной подбор продолжает работать. Автозапуск настраивается отдельно администратором.

## Тексты

Этот анализатор не создаёт таймкоды. Синхронизированный текст отображается, когда подходящая разметка найдена в Navidrome или интернет-источнике. Для отсутствующего текста и неизвестной версии записи полное покрытие всей библиотеки не гарантируется.
