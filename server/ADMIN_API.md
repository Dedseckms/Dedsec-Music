# Администрирование

Профиль `/dedsec/profile/v1/me` возвращает актуальный `isAdmin`. Запросы ниже
используют обычный `Authorization: Bearer <Navidrome JWT>`. Сервер повторно
проверяет роль через Navidrome; обычный аккаунт получает 403.

* `GET /dedsec/profile/v1/admin/me` → `{isAdmin:true}`.
* `GET .../admin/users` → `{users:[{id,username,isAdmin,uploadCount,canDelete}]}`.
* `GET .../admin/users/{id}/uploads?offset=0&limit=50` → `{items,total}`.
  Элемент: `{name,source:"upload"|"yandex",size,createdAt}`; `limit` 1–100.
* `POST .../admin/users` с `{username,password}` → `{user,uploadReady,warning}`.
  Логин: 3–32 латинских символа, цифры, `.`, `_`, `-`. Пароль: от 12 символов,
  не более 128 байт UTF-8. Создаётся обычный аккаунт со всеми текущими библиотеками.
* `DELETE .../admin/users/{id}` → `{ok:true}` только после проверки удаления.

Самоудаление и удаление последнего администратора запрещены. Перед изменениями
создаётся согласованная приватная копия SQLite с `quick_check`. Музыкальные файлы
не удаляются. Удалённый логин нельзя использовать повторно. При неопределённой
ошибке удаления доступ к загрузке остаётся отозванным, сервер возвращает ошибку,
а не ложное подтверждение. Активный импорт отменяется; публикация аудио повторно
проверяет отзыв доступа после приёма файла.

Новый аккаунт использует одинаковые данные Navidrome и проверенного загрузчика.
Для каждого файла действуют общие 100 000 000 байт, 20 минут, проверка реального
аудио и запрет перезаписи. Пароли проходят только через HTTPS и память запроса.

История добавлений начинается с подтверждённой публикации через этот API.
Старые файлы и перенесённые записи без достоверной привязки к человеку не
приписываются по имени файла. Повторное использование общей аудиозаписи при
импорте не считается новой загрузкой. После аварии между публикацией и записью
происхождения файл может отсутствовать в этой истории; аудио сохраняется.

Адаптер другого загрузчика обязан гарантировать отзыв всех его способов чтения
и записи. До включения такой защиты `canDelete=false` и ошибка
`UPLOAD_REVOCATION_UNAVAILABLE` запрещают частичное удаление аккаунта.
